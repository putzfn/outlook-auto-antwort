# Outlook „Auto-Antwort" → Claude.ai

Ein Papierflieger-Button im Outlook-Ribbon (Lesen **und** Inline-Antwort), der den
Volltext der Nachricht als vorausgefüllten Prompt auf **https://claude.ai** im
Standardbrowser öffnet. Absenden erfolgt manuell – es wird nichts automatisch gesendet.

## Struktur

| Pfad | Inhalt |
|---|---|
| `addin/` | Office Web Add-in (Manifest, JS, Icons) – Variante A |
